# Recipe Steps Catalog

This is a practical catalog of built-in recipe steps and their expected shape.
Use it to assemble setup recipes or content imports quickly.
Note: step names appear in different casing across recipes. Prefer the canonical names shown in the files below.

## Step groups
- Core setup (feature/themes/settings/recipes): `RECIPE-STEPS-CORE.md`
- Content definitions (ContentDefinition/Replace/Delete): `RECIPE-STEPS-DEFINITIONS.md`
- Content and media import: `RECIPE-STEPS-CONTENT-MEDIA.md`
- Queries and search indexes: `RECIPE-STEPS-SEARCH.md`
- Security and identity: `RECIPE-STEPS-SECURITY.md`
- Templates and workflows: `RECIPE-STEPS-TEMPLATES-WORKFLOWS.md`
- Other common steps (layers, placements, admin menu, sitemaps, url rewriting, custom settings, tenants): `RECIPE-STEPS-MISC.md`

## Common first steps
- Enable features and set themes/settings: `RECIPE-STEPS-CORE.md`
- Add content types/parts/fields: `RECIPE-STEPS-DEFINITIONS.md`
- Import content and media: `RECIPE-STEPS-CONTENT-MEDIA.md`
- Create roles and users: `RECIPE-STEPS-SECURITY.md`
- Add workflows/templates: `RECIPE-STEPS-TEMPLATES-WORKFLOWS.md`
