# Glossary

- Shape: Renderable object with metadata (type, alternates, differentiator) and properties; rendered by a template.
- Placement: Rules in `placement.json` that decide where/if a shape renders, plus added alternates/wrappers.
- Alternate: A more specific template name Orchard tries when rendering a shape (e.g., `Content__Article`).
- Display type: Rendering mode for a shape (e.g., `Detail`, `Summary`, `SummaryAdmin`), appended to shape type.
