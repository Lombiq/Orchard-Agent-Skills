# Razor Templating

Purpose: Use to implement Razor theme changes with tag helpers, shape rendering, and IOrchardHelper.
- `TAG-HELPERS.md` - tag helper overview.
- `TAG-HELPERS-SHAPES.md` - shape rendering tags.
- `TAG-HELPERS-RESOURCES.md` - scripts/styles/resource tags.
- `TAG-HELPERS-MEDIA.md` - media tag helpers.
- `TAG-HELPERS-CONTENT-MENUS.md` - content and menu tags.
- `TAG-HELPERS-CACHING.md` - cache tag helpers.
- `TAG-HELPERS-UTILITIES.md` - utility tag helpers.
- `ORCHARD-HELPER.md` - IOrchardHelper extensions.

Use this section only when the active theme uses `.cshtml` templates.
