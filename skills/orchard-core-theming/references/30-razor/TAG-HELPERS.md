# Tag Helpers

Razor tag helpers used in Orchard Core themes.
Open only the file you need.

- Shapes and zones: `TAG-HELPERS-SHAPES.md`
- Content and menus: `TAG-HELPERS-CONTENT-MENUS.md`
- Resources and metadata: `TAG-HELPERS-RESOURCES.md`
- Media helpers: `TAG-HELPERS-MEDIA.md`
- Caching: `TAG-HELPERS-CACHING.md`
- Utilities (user, validation, time, captcha): `TAG-HELPERS-UTILITIES.md`
