# Lombiq Orchard Agent Skills

## About

This repository contains Codex Agent Skills focused on Orchard Core development tasks. The skills provide evidence-first, source-aligned guidance for common theming and site setup work (content definitions, recipes, shapes, placement, and templates) to reduce hallucinations and speed up delivery.

## Repository layout

- `skills/` - skill packages.
- `skills/orchard-core-theming/` - Orchard Core theming and content-definition/recipe playbook.

Each skill folder contains a `SKILL.md` entry point plus optional `references/` with task-focused guides.

## Using the skills

- Skills are discovered from the `skills/` folder by Codex.
- For Orchard Core theming, start at `skills/orchard-core-theming/SKILL.md` and then use `skills/orchard-core-theming/references/TASK-MAP.md` to jump to the exact reference file.
